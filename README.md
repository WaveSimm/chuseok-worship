# 2026 추석 가정예배 페이지

`index.html` 한 파일로 된 정적 웹페이지. 홈 화면에서 어머니용(패드·큰 글씨)과 가족용(폰) 두 갈래로 들어간다.
페이지 전체는 비밀번호로 잠겨 있고, 비밀번호는 `.env`에서 관리한다.

| 파일 | 역할 |
|------|------|
| `index.html` | 페이지 본체. 이것만 배포된다 |
| `.env` | 실제 비밀번호. **git에 올라가지 않는다** |
| `.env.example` | `.env` 샘플. 이걸 복사해서 쓴다 |
| `build.py` | `.env`의 비밀번호 → SHA-256 해시를 `index.html`에 주입 |
| `setpw.py` | 비밀번호 바꾸기. `.env`를 직접 열 필요 없다 |
| `비밀번호 바꾸기.bat` | 더블클릭하면 `setpw.py` 실행 |
| `env 파일 열기.bat` | 더블클릭하면 `.env`를 메모장으로 연다 |
| `.gitignore` | `.env`와 잡파일 제외 |

## 예배 개요

- 주제: 대를 이어 흐르는 믿음, 그래서 감사
- 본문: 디모데후서 1장 3~7절 (개역한글)
- 시작 말씀: 시편 100편 교독 (개역한글)
- 참석: 어머니(81세), 동생 부부와 20대 아들 셋, 우리 부부와 20대 딸 둘 — 10명
- 소요: 약 25~30분

## 페이지 구성

주소 해시로 화면을 나눈다. 서버 설정 없이 `index.html` 하나면 된다.

| 주소 | 화면 |
|------|------|
| `/` | 홈. 보름달 아래 "어머니용" / "가족용" 버튼 두 개 |
| `/#pad` | 어머니용. 14장면을 한 장면씩, 하단에 이전·다음 버튼 |
| `/#pad/N` | 어머니용 N번째 장면 (0부터). 화면이 꺼졌다 켜져도 그 자리부터 |
| `/#phone` | 가족용. 역할표와 순서 10개를 한 페이지에 |

어머니용 상단 바:
- 글자 크기 4단계 (34 / 40 / 48 / 58 px), 기본 40
- 밝게/어둡게 전환 (기본은 기기 설정을 따름)
- 두 설정 모두 localStorage에 저장 → 패드에서 한 번 맞추면 유지

외부 의존: Google Fonts(Noto Sans KR)만 쓰고, 안 되면 기기 글꼴로 대체. 찬송 화면의 악보·반주 버튼은 외부 사이트로 새 창 링크.

## 수정 포인트 (`<script>` 상단 상수)

| 상수 | 내용 |
|------|------|
| `THEME` | 주제 문구 |
| `PS100`, `TIM` | 시편 100편, 딤후 1:3~7 본문 (절 번호, 본문) |
| `LYRICS` | 찬송 가사. `587: ['1절 전체', ...]` 형태. 587장·305장 4절씩 채워져 있다. 절 안의 줄바꿈은 \n 문자 |
| `HYMNS` | 장 번호, 제목, 절 수, 악보 링크(`sheet`), 반주 영상 링크(`video`) |
| `POINTS` | 말씀 나눔 요지 3개 |
| `CREED` | 사도신경 (줄 단위) |
| `LORDS_PRAYER` | 주기도문 (줄 단위) |
| `ROLES` | 가족용 상단 역할표 (사회·말씀 나눔 심윤송, 기도 동생, 봉독 손주 다섯, 어머니 기도 어머니) |
| `STEPS` | 순서 10개. 각 항목의 `body`가 폰 화면, `pad` 배열이 패드 장면(사도신경·교독·봉독은 2장면으로 나눠 둠) |
| `SIZES` | 패드 글자 크기 단계 |

봉독 순서 표시는 `readSide`가 "봉독 1~5"로 붙인다. 이름을 넣고 싶으면 이 함수만 바꾸면 된다.

## 비밀번호

페이지에 들어가려면 비밀번호가 필요하다. 한 번 넣으면 그 기기에서는 다시 묻지 않는다(localStorage).

### 바꾸는 법 (쉬운 쪽)

**`비밀번호 바꾸기.bat` 을 더블클릭**한다. 새 비밀번호를 두 번 넣으면
`.env` 갱신 → 해시 주입 → (물어본 뒤) GitHub push 까지 알아서 한다.

### 바꾸는 법 (터미널)

```bash
python setpw.py          # 물어보는 대로 넣으면 끝
```

직접 하고 싶으면:

```bash
cp .env.example .env     # 처음 한 번
# .env 의 WORSHIP_PASSWORD 를 원하는 값으로 고친다
python build.py          # 해시를 index.html 에 주입
```

> `.env`는 윈도우에서 더블클릭으로 안 열린다(확장자가 `ASP.FileEnv`로 잡혀 있다).
> `env 파일 열기.bat` 을 쓰거나, 우클릭 → 연결 프로그램 → 메모장으로 연다.

`.env`는 `.gitignore`에 있어 git에 올라가지 않는다. 배포되는 `index.html`에는 평문이 아니라
SHA-256 해시만 들어간다.

> 한계: 저장소가 public이라 `index.html` 소스는 누구나 볼 수 있다. 잠금은 주소를 우연히
> 연 사람을 막아주는 수준이지, 저장소를 찾아낸 사람까지 막지는 못한다. 링크를 가족에게만
> 공유하는 전제로 쓴다. 검색 노출은 `noindex` 메타로 막아 뒀다.

## 배포 (GitHub Pages, gh CLI)

이 폴더 자체가 저장소다. 처음 한 번:

```bash
python build.py                      # .env 비밀번호를 index.html 에 반영
git init -b main
git add .                            # .env 는 .gitignore 로 자동 제외
git commit -m "추석 가정예배 페이지"

gh repo create chuseok-worship --public --source=. --push

# Pages 켜기 (main 브랜치 루트)
gh api -X POST "repos/{owner}/{repo}/pages" --input - <<'EOF'
{"source":{"branch":"main","path":"/"}}
EOF

# 주소 확인 (첫 빌드는 1~2분)
gh api "repos/{owner}/{repo}/pages" --jq .html_url
```

결과 주소는 `https://<아이디>.github.io/chuseok-worship/`.
어머니 패드용 링크는 뒤에 `#pad`를 붙인다: `https://<아이디>.github.io/chuseok-worship/#pad`

이후 수정은 `index.html` 고치고 `git commit -am "가사 수정" && git push`.
비밀번호를 바꿨다면 push 전에 `python build.py`를 먼저 돌린다.

Vercel을 쓰려면 같은 폴더에서 `npx vercel --prod` 한 줄로도 된다.
