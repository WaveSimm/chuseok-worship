# 악보 이미지 폴더

| 파일 | 찬송 | 크기 |
|------|------|------|
| `587.jpg` | 587장 감사하는 성도여 | 622×860 |
| `305.jpg` | 305장 나 같은 죄인 살리신 | 700×628 |

찬송 화면에서 가사 아래에 화면 폭 가득 자동으로 확대되어 표시된다.

## 바꾸거나 더할 때

- 같은 이름으로 덮어쓰면 그대로 바뀐다.
- 파일 이름이나 확장자를 바꾸려면 `index.html`의 `HYMNS` 안 `img` 값을 고친다.
- 파일이 없으면 그 자리는 조용히 사라진다. 깨진 이미지는 안 나온다.
- 바꾼 뒤 `git add sheets && git commit -m "악보 교체" && git push`.

## 참고

- 원본 파워포인트(`*.ppt`)는 `.gitignore`에 있어 배포되지 않는다. 웹에서 열 수 없고 용량만 크다.
- 폭이 넓은(가로로 긴) 이미지일수록 패드에서 시원하게 보인다.
