# 악보 이미지 폴더

여기에 악보 이미지를 넣으면 찬송 화면에 바로 뜬다.

| 파일 이름 | 찬송 |
|-----------|------|
| `587.png` | 587장 감사하는 성도여 |
| `305.png` | 305장 나 같은 죄인 살리신 |

- 파일이 없으면 그 자리는 조용히 사라지고 기존 링크 버튼만 남는다. 깨진 이미지는 안 나온다.
- 파일 이름을 바꾸거나 `.jpg`를 쓰려면 `index.html`의 `HYMNS` 안 `img` 값을 고친다.
- 가로로 긴 이미지가 좋다. 화면 폭에 맞춰 자동으로 늘어난다.
- 넣은 뒤 `git add sheets && git commit -m "악보 추가" && git push`.
